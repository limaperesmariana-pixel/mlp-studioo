# MLP Studio

Site estático, baseado na versão 08 aprovada. O arquivo index.html contém HTML, CSS, Bootstrap, JavaScript e imagens incorporadas.

## GitHub Pages
1. Extraia este ZIP.
2. Envie index.html e .nojekyll para a raiz do repositório.
3. No GitHub, abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch, branch main, pasta / (root), e Save.

Não requer backend ou banco de dados. Confira os links de WhatsApp e Instagram antes de publicar. Confirme que tem autorização para publicar as fotos e capturas do portfólio.
